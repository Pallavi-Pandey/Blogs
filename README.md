# Personal Blogs

A collection of professional guides, setup scripts, and technical articles for maintaining a clean and efficient development environment on Ubuntu.

## Project Structure

This repository is organized into several key areas:

### Automated Setup
- **[dev-environment-setup/](./dev-environment-setup/)**: An industry-standard, single-command installer for a complete Ubuntu developer environment.
  - Installs: VS Code, Docker, PostgreSQL, Python, Git, and more.
  - Supports: Ubuntu 22.04 and 24.04.

### Technical Guides
- **[Installation Guide](./installation-guide.md)**: Manual step-by-step instructions for installing core development tools.
- **[Using uv with Python Projects](./uv-virtual-environment.md)**: A deep dive into using `uv` for modern Python project management and virtual environments.

## How to Use This Repository

1. **New Machine Setup**: Navigate to the `dev-environment-setup` directory and follow the instructions in its README for an automated install.
2. **Reference**: Browsing the markdown files in the root directory for specific tool configurations or best practices.
